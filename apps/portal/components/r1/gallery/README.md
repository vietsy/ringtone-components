# gallery

The specimens shown at `/design-system`: each R1 component in the states the design system draws, so a
change to a component can be seen in every state before a screen uses it.

    specimen.ts    the shape of one specimen: name, group, height, render
    specimens/     one file per component, and the list in the design system's order
    gallery.css    the gallery's own layout around the specimens; the components bring r1.css
