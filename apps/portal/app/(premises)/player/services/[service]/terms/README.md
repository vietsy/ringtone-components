# terms

    page.tsx    SCR-VEN-02  accept the service terms

The premises service terms in the version PUB has in effect today (version 3 in the seed; a version staff publish
on PUB is offered from the day it takes effect), with the way to PUB's published text (SCR-PUB-10); the baseline
that decides what plays; and the attestation, unticked each time the page opens. The digest of the text rendered
goes with the acceptance. Accepted, SCR-VEN-04 opens active; refused, the code is above the action row, and
NO_DEFAULT_CONTENT carries "Đặt danh sách mặc định" to SCR-VEN-06. A version that took effect after the page opened
is refused TERMS_VERSION_SUPERSEDED, which clears the tick and shows the new text. Terms PUB cannot answer are the
Error state, with nothing to accept. Opened for a service no longer pending, the page says ENTITLEMENT_NOT_PENDING.
Views: not-authorised, loading, error.

An active service keeps the version it accepted (CFG-293: the effective version is required at enrolment only), so a
new version asks nothing of it.

- The terms are shown whole rather than in a scrolling region, so "Read the full terms" has nothing to expand.
