    page.tsx   SCR-COM-10  my notice

The six elements in a person's order: what this is about, what you need to do, by when, what happens if you do
not, who to contact (the reference is the title), in the words of the template version it was composed from. A
reissued notice says when it was replaced and opens the current one; the reissue names the notice it replaces and
why. A reference that names no notice the recipient was sent is NOTICE_NOT_FOUND; a signed-in principal
opening a notice addressed to another party is ROLE_OUT_OF_SCOPE. Every read is recorded.
