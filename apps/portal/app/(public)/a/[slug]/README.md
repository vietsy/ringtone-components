The artist's display name and public repertoire, each recording linking its track page (SCR-PUB-09). At P1 ART
offers no public reader, so every profile answers SOURCE_UNAVAILABLE, drawn as the board's P1: "RightOne chưa cung
cấp thông tin này.", nothing older shown. An address not of a slug's form (1 to 80 of `[a-z0-9-]`) names no
profile: ARTIST_NOT_PUBLIC, the one answer for no profile and one not public.

`?view=` shows any view the canvas drew: p1-not-offered, populated (Ngân Mộc and three recordings),
source-unavailable (with "Thử lại" to this address), not-public, loading.

Deviation: the biography in the populated view is the artist's own words, data rather than interface copy, so it
reads in Vietnamese in either language.
