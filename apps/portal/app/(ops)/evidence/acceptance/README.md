# acceptance

SCR-PLR-07 Evidence acceptance: the latest batch from the device chosen above (the latest to arrive by default), the
outcome of each event with the refusal's code where one applies, and the events quarantined rather than refused. A
device that has sent nothing says since when. Open the disposition is left out: SCR-PLR-09 is not built.

The auditor (ACT-AUD) reads it too (PERM-484), and both the auditor and the operations officer open the device's
record (SCR-PLR-02) from it. The contract's period filter and per-event list are not drawn: the mock holds batches
with their outcome counts, not the events a device sends, which only the device's evidence submission would create.
