# assurance-policy

SCR-PLR-11 on the evidence console: the device-assurance policy as the evidence operator (ACT-EVD) keeps it. Draft
saves a version in DRAFT with the four parts FR-PLR-043 names (criteria, issuing authority, validity in months,
withdrawal grounds) and its effective date, refused POLICY_VERSION_INCOMPLETE naming the part left out. Approve, on
each draft, approves it and, with "Công bố ngay" ticked, publishes it; refused EFFECTIVE_PERIOD_OVERLAPS naming the
version already in force for part of its period. An approved version kept unpublished is published from its own
panel. Only a published version is read on the public page (`/player-assurance-policy`) and applied against.

- The specification lists POST /assurance-policy-versions for SCR-PLR-11 and draws no control for it, nor any screen
  for its approval; SCR-PLR-11 is a public page that takes no act, so both sit here, on the evidence console.
- A new version's full text is its criteria as written: the form has no field for the numbered sections version 2
  publishes, and a refusal's criterion still comes from those numbers.
