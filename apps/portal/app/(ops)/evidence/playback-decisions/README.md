# playback-decisions

SCR-PLR-15 Playback decisions: a device's decisions on one local day, of every kind or one, with the rule set applied.
`export/route.ts` is Export the day, the day's decisions as CSV with the rule-set version on each line.

The rule set named is the version in force on the day shown (AC-FR-PLR-022-02), read from the rule-set versions the
evidence operator drafts and approves; "Các phiên bản" on the rules panel opens them (`../playback-rules`).
