# offline-continuity

SCR-PLR-13 Offline-continuity policy: the form starts from the latest draft and saves a new draft version, refused
POLICY_INCOMPLETE naming the part left out. Approve, beside the draft with an optional note the audit record keeps,
checks the four parts again (POLICY_INCOMPLETE) and the period (EFFECTIVE_PERIOD_OVERLAPS naming the version in the
way). An approved version governs from its effective date: until then the interim rule of BR-PLR-19 stays in force,
and the page says which bounds a session opening now.

- The specification draws no control for POST /offline-continuity-policy-versions/{id}/approve; Approve sits here,
  on the screen that shows the draft it acts on.
- The specification names no rule that the approver differ from the drafter, so none is applied.
