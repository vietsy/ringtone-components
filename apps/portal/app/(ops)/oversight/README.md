# oversight

The oversight console ("Giám sát", `components/shells/ops-nav.ts`): what the supervising authority (ACT-REG) and the
auditor (ACT-AUD) read, in aggregate, and never act on.

    inspections/   SCR-VER-16  Oversight of inspections and supplies
    verification-counts/   SCR-PUB-19  Verification outcome counts (ACT-REP, ACT-SEC)
    disclosure-profile/    SCR-PUB-20  Disclosure profile in effect (ACT-DPO, ACT-SEC)
