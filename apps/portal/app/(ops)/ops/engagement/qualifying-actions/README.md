# qualifying-actions

    page.tsx   SCR-ENG-08  `?participant=&at=` resolves the governing version and the codes it lists for the
               participant's class; Record posts the action with its subject (a track, or none) and the display
               profile it happened under; `?recorded=` names the event recorded

The value is resolved, never typed. AWARD_RULE_NOT_EFFECTIVE routes to the policy preparer, AWARD_RULE_WITHDRAWN names
the version, when it was withdrawn and by whom. Two tracks published at one instant are two actions by their subject;
the same act recorded again under another profile is QUALIFYING_ACTION_CONFLICT, naming the event and the correction
route.
