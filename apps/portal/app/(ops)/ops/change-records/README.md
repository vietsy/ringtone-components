# change-records

    page.tsx   FR-PTY-048  the change records of the party register, for a period (GET /change-records)

On the register data console, for the data owner (ACT-DAT) and assurance (ACT-AUD), read only. Every change to a party,
a person, an authority or a premises, with the person or the process that made it, what it relied on - a premises
actor's authority and its version, an officer's permission row, a sweep's rule (@AC-FR-PTY-048-04) - and the instant.
A period is required: an empty one is PERIOD_REQUIRED, and no period is chosen on the reader's behalf. No screen code
is assigned to this read yet (`design/01-screen-inventory.md` lists none); it is reached from the console's rail.
