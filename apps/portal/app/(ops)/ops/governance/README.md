# governance

Governance screens in the Operations Console. These routes require a staff session; organisation administrators use `/org/mandate` for `SCR-GOV-14`, their own mandate.

    mandates/page.tsx                 SCR-GOV-01  mandate register
    mandates/[mandateId]/page.tsx     SCR-GOV-02  mandate detail
    coverage/page.tsx                 SCR-GOV-03  coverage lookup
