The boards draw these three as a surface of their own, "Báo cáo và chính sách", with its own rail. The portal has
three consoles, so the surface lives in the operations console's Reports workspace and its three entries are link
tabs, each offered only to the roles that read it. Every page is read only.

- SCR-REG-16 opens on the current calendar month (the specification; the board shows September). The board's
  September figures count where a period covers that whole month, with every application of this world that ended
  in the period. Nothing is measured while CER's record event is not consumed (P1): the completion panel says so,
  never 0, and the interim reading to the decision stands under its own heading.
- A report row opens its case file where this world holds the application; the others have no link.
- SCR-REG-17 reads the versions in force at the instant chosen, now by default.
