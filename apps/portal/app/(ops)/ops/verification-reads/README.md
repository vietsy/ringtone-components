# verification-reads

    page.tsx   SCR-PTY-18  the overlap report: the verification reads of one premises (GET /premises/{id}/verification-reads)

On the register data console, for the data owner (ACT-DAT) and assurance (ACT-AUD), read only: which collecting
organisations asked about the premises through the verification route (SCR-PTY-17), about which moment, and what each
was told, optionally from and to a day. A collecting organisation is refused the same report on its own portal
(`app/(org)/org/verify/overlaps`, OVERLAP_REPORT_RESERVED).
