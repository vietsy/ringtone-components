# templates

    page.tsx    SCR-COM-04  the template versions of one class of the policy in force (`?class=`), the ones composing
                today or on a day asked (`?as-of=`, the contract's `as_of`), a preview of the six elements,
                preparing a version and approving one somebody else prepared

A version's body is the notice's wording: each element starts a line with its placeholder, and the words after
`{subject}`, `{action}` and `{consequence}` are what the recipient reads, with the record's values (`{case}`) filled
in. The version in force at composition is kept with each notice, so approving a new one changes no notice sent.
