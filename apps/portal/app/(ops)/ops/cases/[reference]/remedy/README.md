# remedy

    page.tsx   SCR-CAS-10  remedy linkage

Each reference is read in the module that holds it (TAR, FIN, COM, CER) through that module's exported read; the
artefact names the case when the case's reference is in what the module answers for it. A refund recorded on
SCR-FIN-10 under the case names it, and so do the calculation it links in TAR and the corrective document its sending
produces; the original invoice and the fee's first calculation do not. While no refund is linked, the finance officer
is sent to record it there with the case filled in.
