    page.tsx                    SCR-REG-10  application case file
    evidence-request/page.tsx   SCR-REG-11  request evidence
    claims/[claim]/page.tsx     SCR-REG-12  claim review, one claim of the application
    proposal/page.tsx           SCR-REG-13  decision proposal
    withdrawal/page.tsx         SCR-REG-15  record a withdrawal on instruction

The case file is the hub: every act opens from it and returns to it, each disabled with the sentence that holds it
(convention 14). Correct a fact opens under the facts and asks before it records a new version labelled
RightOne's. The data owner (ACT-DAT without ACT-OPS) reads it without the acts, with each registry fact's source.

- A part of a record the boards never draw (the facts of an application listed only in the queue) says the
  sample data does not hold it, rather than show an empty list in its place.
- The business registration stays masked: the data holds only the masked number, so there is no Show control.
- Start an amendment opens under the acts of a decided application whose decision is current (an appeal outcome,
  with its decided CAS case, or a reconciled classification); the new draft's case file opens, and Send the
  amendment in its header puts it in the amendment review once nothing holds it.
