# [authority]

    page.tsx    SCR-PTY-13  one authority on the security console, read only

The security admin and assurance (ACT-SEC, ACT-AUD) read an authority to act for a party: its versions, the acts
performed under it, and for a revocation who made it, from when, why and where it reached. A decision point that has
not confirmed it stopped granting carries the exception it raised. The principal grants, amends and revokes on the
premises portal (`app/(premises)/authorities/`); this page has no act.
